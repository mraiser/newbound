Groups ·

The library gate: comma-delimited security groups, written to meta.json as both the groups string and the enforced readers array (set_groups). Empty = admin-only. The convention for a library serving non-admin users is anonymous here, with fine-grained groups on individual controls and commands. Takes effect on restart.

Assets ·

The library's _ASSETS files, served at /app/asset/<lib>/<name>. Writes go through the write API (write_asset/rename_asset/ delete_asset), journal-free but admin-gated.

Rust settings ·

Rust settings — meta.json's root, cargo.crate_types, cargo.dependencies. Inert until this library contains Rust; editable so adding Rust later has a defined home. Saved via dev.libsettings.save_library_config.

Rebuild ·

Regenerates and recompiles this library's commands from the store (dev.dev.rebuild_lib) — the old dev UI's build button. Store edits (upserts, moves) can leave compiled code behind the records until a rebuild or restart; this is the deliberate catch-up act. Slow for big libraries; the instance keeps serving.
